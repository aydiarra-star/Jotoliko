# UX Livreur 2026

## Ma journée
1. Mission actuelle
2. Client + téléphone
3. Quartier + zone + repère
4. Instructions
5. Montant attendu
6. État de synchronisation

Actions primaires : Appeler, Naviguer, Arrivé, Preuve, Livré, Encaisser, Problème.

Le livreur doit pouvoir travailler sur un téléphone Android peu puissant, avec réseau intermittent. Une action hors ligne n'est jamais annoncée comme synchronisée avant confirmation serveur.
