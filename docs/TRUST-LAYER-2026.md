# Trust Layer

Chaque information opérationnelle possède un niveau de vérité explicite.

- RÉEL : reçu d'une source opérationnelle réelle.
- ESTIMÉ : calculé à partir de données réelles et signalé comme estimation.
- DERNIÈRE POSITION CONNUE : position réelle mais non récente.
- INDISPONIBLE : aucune donnée exploitable.
- À VÉRIFIER : incohérence ou donnée incomplète.
- CONFIRMÉ : validé explicitement par un acteur autorisé.

Interdictions : faux temps réel, faux ETA, faux KPI, faux GPS, faux paiements, faux témoignages.
