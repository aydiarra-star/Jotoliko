# Jotoliko OS — Operations terrain africaines 2026

## Positionnement
Jotoliko devient un OS des opérations terrain : commandes, missions, tournées, équipes, GPS, preuves, encaissements, remises, rapprochements et anomalies.

## Source de vérité
Le produit ne présente jamais une donnée absente comme réelle. Les états de confiance sont : RÉEL, ESTIMÉ, DERNIÈRE POSITION CONNUE, INDISPONIBLE, À VÉRIFIER, CONFIRMÉ.

## Personas
- Responsable : Centre opérationnel / Aujourd'hui.
- Livreur : Ma journée, mobile-first.
- Vendeur : Mon activité.
- Client : suivi sans application obligatoire.

## Chaîne
Commande → Affectation → Départ → Arrivée → Preuve → Livraison → Paiement → Remise → Rapprochement → Clôture.

## Finance
EXPECTED / COLLECTED / REMITTED / DIFFERENCE sont distincts. Les corrections financières sont des événements audités, jamais une mutation silencieuse du montant historique.

## Afrique
Adresse structurée : pays, ville, quartier, zone, adresse écrite, repère, instructions, GPS si disponible, précision, photo si disponible.

## Limites actuelles
Le dépôt public actuel contient principalement le site marketing statique. Les capacités serveur, authentification réelle, multi-tenant côté serveur, stockage de preuves et synchronisation serveur doivent être branchées avant toute promesse de production. Cette limite est volontairement visible et ne doit pas être masquée par l'interface.
